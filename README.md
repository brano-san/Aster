## Fast, native GPU-accelerated terminal

**Aster — терминал для Windows и Linux, написанный на Rust.** Никакого браузерного движка или WebView: интерфейс и сетка символов отрисовываются **собственным нативным GPU-пайплайном** (Direct3D 11 + DirectComposition + DirectWrite на Windows, OpenGL ES 3.0 + EGL + HarfRust + Swash на Linux под Wayland и X11).

Вкладки и разделение на панели, профили и автоопределение оболочек (PowerShell, CMD, WSL, Git Bash, MSYS2, Cygwin), SSH и SFTP, последовательный порт и Telnet, хранилище секретов, режим Quake, цветовые схемы и гибкие горячие клавиши.

## Getting Aster

Готовые сборки — на странице [Releases](https://github.com/brano-san/Aster/releases):

* **Windows 10/11:** запустите `aster-<версия>-x86_64-windows-setup.exe` и выберите папку установки и ярлыки. Права администратора не нужны. Для запуска из папки скачайте ZIP и откройте `aster.exe` после распаковки.
* **Linux (Wayland / X11):** скачайте `aster-<версия>-x86_64-linux.tar.gz`, распакуйте и запустите `./aster`. Нужны EGL / OpenGL ES и xkbcommon (на Debian и Ubuntu: `libegl1`, `libgles2`, `libgl1-mesa-dri`, `libxkbcommon-x11-0`); сборка совместима с glibc 2.35 (Ubuntu 22.04) и новее.

Откройте настройки шестерёнкой справа в полосе вкладок или нажмите `Ctrl+,`. Файл `config.toml` создаётся при первом запуске в `%APPDATA%\Aster` (Windows) или `~/.config/aster` (Linux).

В Linux ярлык со значком можно создать в разделе «Настройки → Приложение → Добавить в меню приложений». Для установки средствами дистрибутива архив также содержит `share/applications/aster.desktop` и значки hicolor.

В Windows 11 со штатным консольным провайдером откройте «Настройки → Приложение → Сделать Aster терминалом по умолчанию». Новые консольные приложения будут открываться во вкладках Aster. Там же можно вернуть прежний выбор.

## Работа с выводом

- `Ctrl+Shift+G` отмечает видимые ссылки, пути и хеши, включая текст с мягкими переносами. Введите метку, чтобы скопировать объект. `Ctrl+Shift+H` открывает выбранную ссылку или локальный путь. Для перехода к строке и столбцу в пути вида `src/main.rs:42:7` задайте `ASTER_FILE_EDITOR` с путём к редактору, поддерживающему `--goto`. По умолчанию Aster открывает файл в текстовом редакторе, а при его отсутствии открывает папку с файлом.
- `Ctrl+Alt+F` ищет по выводу всех открытых вкладок и панелей окна. Стрелки выбирают результат, Enter переходит к совпадению, Esc оставляет текущую панель.
- `Ctrl+Shift+U` открывает историю команд активной панели. Введите часть команды, чтобы найти её. `Ctrl+C` копирует вывод выбранной команды, а `Enter` открывает поиск только по её выводу. В результатах `Enter` переходит к совпадению, `Ctrl+C` копирует найденный фрагмент. История, переходы по приглашениям и копирование вывода последней команды используют метки OSC 133, если оболочка их передаёт.
- В SFTP можно переходить по сегментам пути. Если удалённая оболочка сообщает CWD через OSC 7, OSC 9;9 или OSC 1337, файловая панель может открыться в этом каталоге. Для возврата туда служит кнопка «Каталог оболочки». Если оболочка не сообщает CWD, панель использует сохранённый или домашний каталог. Команда «Передачи SFTP» (`Ctrl+Shift+Y`) показывает передачи из всех вкладок окна.

## Рабочие пространства

В палитре команд (`Ctrl+Shift+P`) можно создать, переименовать или переключить рабочее пространство окна. Новое пространство открывается на стартовой странице. Вкладки, разделённые панели и положение прокрутки остаются на месте, а локальные и SSH-сеансы продолжают работать в фоне. При включённом восстановлении сессии Aster открывает прежние пространства и выбирает последнее активное.

## Сниппеты и задачи

Откройте палитру команд через `Ctrl+Shift+P` и найдите сниппет по имени, тегам или тексту. `Enter` вставляет найденный сниппет в активную панель для редактирования. Если программа не поддерживает bracketed paste, переводы строк заменяются пробелами.

Выделите текст в терминале и выберите «Сохранить выделение как сниппет» в контекстном меню или палитре. Команда «Управление сниппетами» открывает файл настроек, где можно изменить имя, текст и теги или удалить запись.

```toml
[snippets."Состояние репозитория"]
text = "git status --short"
tags = ["git", "repo"]
```

После завершения задачи, запущенной через `aster run`, Aster показывает код выхода, если панель остаётся открытой по политике профиля. Кнопка «Повторить задачу» снова запускает исходную команду с теми же аргументами и рабочей папкой в той же панели. Действие также доступно в контекстном меню и палитре команд.

## Воспроизведение ошибок терминала

В палитре команд выберите «Открыть вкладку для записи фикстуры терминала» или запустите `aster --record-vt-fixtures`. Повторите сбой в этой вкладке и выберите «Сохранить фикстуру терминала». Aster запишет файл `aster-fixture-*.json` в папку загрузок. Запись хранится в памяти панели до её закрытия. Файл содержит вывод терминала, включая возможные конфиденциальные данные.

`aster --replay-vt-fixture FILE` проверяет версию формата, размеры, видимые клетки, курсор и историю команд при четырёх способах разбиения потока. Воспроизведение учитывает изменения размера и восстановленный вывод. Оно выполняется без окна, оболочки и PTY. Запись прекращается после 1 МиБ вывода или 8192 событий. Сохранение требует полной записи с начала панели.

## Доступность

В Windows Aster предоставляет данные программам чтения с экрана через UI Automation, в Linux — через AT-SPI. Доступны вкладки, палитра команд, поле поиска и видимый текст активной панели вместе с позицией курсора и выделением. `Esc` закрывает палитру или поиск и возвращает фокус в терминал.

## Compiling from source

Нужен актуальный **Rust stable**.

#### Windows (MSVC)

Нужны инструменты MSVC и Windows SDK с MIDL.

```powershell
git clone https://github.com/brano-san/Aster.git
cd Aster
cargo build --release
# target\release\aster.exe
```

#### Linux (Wayland / X11)
Для запуска нужны EGL / OpenGL ES и XKB (на Ubuntu: `libegl1`, `libgles2`, `libgl1-mesa-dri`, `libxkbcommon-x11-0`), для сборки — компилятор C и стандартные инструменты.

```bash
cargo build --release -p aster
```
