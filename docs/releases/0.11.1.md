Aster 0.11.1 adds default terminal support on Windows 11 and a Settings button.

## New

- On Windows 11 with the system console provider available, open Settings → Application → Make Aster the default terminal. New console applications open in Aster tabs, including when Aster is already running. Restore the previous terminal from the same page.
- Open Settings from the gear at the end of the tab bar. The button works with the tab bar on any edge.
