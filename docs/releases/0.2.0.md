Aster 0.2.0 adds a built-in SSH client, a settings screen, session restore, buffer search and a Quake-style mode.

## New

- Built-in SSH client. Hosts from ~/.ssh/config appear as profiles, and typing user@host:port in the profile selector (Ctrl+Shift+E) connects directly. Login tries the SSH agent (the OpenSSH agent or Pageant on Windows, SSH_AUTH_SOCK on Linux), your keys with a passphrase prompt, keyboard-interactive and password. Host keys are checked against ~/.ssh/known_hosts: new hosts are confirmed by fingerprint, changed keys are refused. ProxyJump chains and ProxyCommand work as in OpenSSH. Prompts appear right in the pane. Set "SSH client" to "System OpenSSH" in the settings to use the ssh program instead.
- Settings screen (Ctrl+,) with search. Changes apply at once and are saved to config.toml.
- Search in the scrollback (Ctrl+Shift+F) with regular expressions, case and whole-word options. Results stay current while output streams in, every match is highlighted, the scrollbar edge shows where matches are, and the bar counts them.
- Session restore: windows, tabs, splits, profiles, working directories and the last screen of output come back on start. Turn it off with "Restore tabs".
- Quake-style mode on Windows: dock the window to a screen edge and show or hide it from anywhere with a global hotkey (Ctrl+` by default).
- Window opacity, and the Mica and Acrylic backdrops on Windows 11.
- Context menu for tabs: new, duplicate, rename, move, close, close other tabs, close tabs to the right or left. Double-click a tab to rename it; custom names survive a restart.
- Context menu for the terminal when right click is set to "Context menu".
- Pasting several lines into a program that would run each one asks first, with a preview and a "Paste as one line" choice.
- Bell: flash the pane, play the system sound, or do nothing.
- New tabs and splits follow the folder of PowerShell and CMD too, and of any shell that does not report its folder.

## Fixed

- Choosing a profile or menu item with Enter no longer sends an extra Enter to the new tab.
