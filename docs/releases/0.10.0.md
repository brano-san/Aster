Aster 0.10.0 fits into the desktop on Windows and Linux, takes SSH much further, and brings a color scheme editor, pane rearranging, a full vault screen and a built-in config editor.

## New

- Desktop integration on Linux: add Aster to the applications menu with its icon, a New window action and your profiles; `aster -e <command>` and `--working-directory` so Aster can be the default terminal; "Open in Aster" in Nautilus, Nemo, Dolphin and Thunar.
- Desktop integration on Windows: "Paste path" in the Explorer menu for files and folders, a Start menu shortcut, a taskbar jump list with profiles and recent folders, and `aster://profile?profileName=...` links (off by default).
- Start Aster when you sign in, hidden in the tray or the docked window when those are enabled.
- SSH: connect through a proxy command, another profile as a jump host, SOCKS5 or HTTP CONNECT; choose the login method; set or forget the saved password from the editor. New profile editor tabs for port forwards, advanced options and algorithms. Agent forwarding, one connection shared by several tabs, a panel for keyboard-interactive logins and a tab toolbar to reconnect, open SFTP and see the forwards.
- Vault screen: typed entries (SSH passwords, key passphrases, key files) with show, copy, rename, replace, export and delete; set, change or wipe the master password; choose how long the vault stays unlocked; optionally encrypt the whole config file, unlocked when Aster starts.
- Color schemes: dark and light tabs, a scheme editor with a live sample, a Colors tab in the profile editor, an optional 256-color palette generated from the scheme, font weights with a live sample, interface colors taken from the terminal scheme and a background image.
- Panes: names shown in a pane header, switching the profile of a running pane, a rearrange mode with labels, dragging panes and whole tabs into splits with drop zones, moving a pane to its own tab, a resize step and focus that follows the mouse.
- Notifications when a command finishes or a background tab shows activity; the docked window can be placed on a chosen screen and follows monitor changes; an optional profile sidebar.
- Shortcuts: defaults that suit each OS, mouse buttons, the wheel and bare modifiers as shortcuts, shortcuts that open a profile or a section or group of the profile selector, context menu items in the command palette and a list of commands hidden from it.
- Quick connect for Telnet, TCP and serial ports (`COM3@9600`) next to SSH, with a choice of the default type.
- Settings: a built-in config file editor with syntax checking and the defaults beside it, a restart button for settings that need it, sliders and color fields, an Advanced tab for profiles, automatic names and an icon picker for new profiles.
- Environment variables shared by every local shell, `%VAR%` and `$VAR` expansion, and new tabs on Windows pick up environment changes made after Aster started.
- Serial ports: mark and space parity, one and a half stop bits and XANY flow control.

## Changed

- The config file has a schema version and is migrated automatically; Aster now writes only the settings you changed.
- Russian plural forms and translated SSH and system errors.
- Pasted text with mixed line breaks is handled the same way in the warning, the preview and the paste itself.
