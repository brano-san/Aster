Aster 0.11.0 brings motion to the whole interface, extensions, config sync, shells that survive a restart and a per-user installer for Windows.

## New

- Animations across the interface: dialogs and the command palette fade and scale in, menus unfold from the click point, toasts and notices fade out, hover highlights cross-fade, tabs slide in and out, panes grow from the split line, side panels and the search bar slide, switches, check marks and expand arrows move, and lists scroll smoothly. Everything follows the Animations setting and the system's animation preference on Windows and Linux.
- A smooth cursor blink style (`terminal.cursor-blink-style = "smooth"`).
- One spinner for every busy state: SSH connecting, update downloads, SFTP and ZMODEM transfers and command checks; progress bars move smoothly.
- Extensions: external programs that talk JSON-RPC over stdin and stdout can add commands to the palette, shortcuts and context menus, color schemes and profiles. A new Extensions page lists installed extensions, enables, disables and removes them, installs from a zip file and from an extension catalog address you set.
- Config sync through a folder (for example one kept by a cloud drive) or a Git repository: choose which parts to sync (shortcuts, appearance, profiles, terminal settings, the encrypted vault), upload, download, delete and upload as new, with optional automatic sync and conflict copies.
- Keep shells running when the window restarts (`terminal.persistent-sessions`): local shells live in a per-user background host, and after an update, a restart or a crash the new window reattaches them with their recent output.
- Install Aster for the current user without administrator rights: run `aster-<version>-x86_64-windows-setup.exe` or `aster --install`; Aster appears in installed apps and uninstalls cleanly, and updates keep working.
- SSH: add and stop port forwards on a live connection from the tab's Ports list, optionally saving them to the profile.
- Buffer search: the overview ruler shows the visible part of the buffer and jumps to a position on click.
- Settings sections can be collapsed.

## Changed

- The Quake window slides down from the top of the screen and back up where the system allows it.
- The visual bell fades instead of flashing.
