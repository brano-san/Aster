The first release of Aster, a native GPU-accelerated terminal for Windows and Linux.

## New

- Native rendering: Direct3D 11 with DirectComposition and DirectWrite on Windows, OpenGL ES 3 with HarfRust and Swash on Wayland and X11. No Electron, no WebView.
- Terminal emulation on alacritty_terminal: 256 colors and true color, bold, italic, dim, inverse, strikethrough, single, double, curly, dotted and dashed underlines with their own color, the alternate screen, mouse reporting, bracketed paste and 25,000 lines of scrollback that reflow on resize.
- Box drawing, block elements, shades and Powerline separators are drawn to fit the cell, so lines join without gaps.
- Tabs in the title bar: drag to reorder, middle-click to close, Snap Layouts on the maximize button on Windows.
- Split panes in four directions with draggable dividers, focus by direction, and maximize of the active pane.
- Shells found automatically: PowerShell 7, Windows PowerShell, CMD, every WSL distribution, Git Bash, Cygwin, MSYS2, Cmder and Visual Studio Developer Prompts on Windows; the login shell and /etc/shells on Linux.
- New tabs and splits start in the working directory of the active pane when the shell reports it (OSC 7, OSC 9;9, OSC 1337).
- Command palette (Ctrl+Shift+P), profile selector (Ctrl+Shift+E) and a color scheme selector that previews while you move through 191 bundled schemes.
- Configurable hotkeys and action ids, including multi-key chords.
- Selection by character, word and line, copy on select, right click to copy or paste, smart Ctrl+C, clickable URLs and file paths.
- Settings in config.toml (%APPDATA%\Aster on Windows, ~/.config/aster on Linux), reloaded when the window regains focus. The window remembers its position and size.
