Aster 0.12.0 makes it easier to open a tab with a specific profile, updates the Application settings page and introduces a new app icon.

## New

- The arrow next to `+` lists the profiles available for a new tab. Click `+` to open the default profile.
- Aster discovers SSH profiles from OpenSSH's `~/.ssh/config` and from `ssh-profiles.yaml` in the Aster config directory or in the directory named by `ASTER_SSH_PROFILES_DIR`. Windows also discovers more local shells, including Cmder, Clink and Visual Studio developer prompts.
- Set terminal text padding independently on each side. On Windows 11 and supported Wayland compositors, adjust background blur when opacity is below 100%.
- The Application settings page shows the app version, update controls, links to GitHub and release notes, and an Accessibility section.
- New application icons for Windows and Linux, including the Windows installer and the Linux desktop launcher.

## Changed

- Settings sections stay expanded, and settings that previously used sliders now use dropdowns.
- Font suggestions appear even when the font field is empty. The Color scheme page also shows the live font sample.
- Closing the last tab keeps Aster open by default. Enable “Last tab closes the window” to close the window with the last tab.
- Restored terminal history starts above the new session's visible area and remains available by scrolling up.

## Fixed

- Mouse wheel scrolling in terminals with long histories.
- The terminal uses the arrow pointer by default, and text can still be selected.
- More space between tab profile icons and titles.
