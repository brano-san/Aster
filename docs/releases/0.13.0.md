Aster 0.13.0 adds workspaces, tools for finding and reusing terminal output, and native screen-reader integration.

## Workspaces and terminal output

- Create, rename, and switch workspaces from the command palette. Keep each workspace's tabs, panes, and scroll positions while its sessions keep running in the background.
- Search output across open tabs and panes with Ctrl+Alt+F. Use Ctrl+Shift+U for the active pane's command history, then open or copy the output of a particular command. Command ranges use OSC 133 shell integration marks.
- Use Ctrl+Shift+G to pick and copy a visible link, path, or hash. Ctrl+Shift+H opens the selected link or path.
- Save selected text as a snippet and insert snippets from the command palette. Rerun a completed `aster run` task in the same pane.

## SSH and SFTP

- Open SFTP in the current directory reported by the remote shell, jump back to it from the file panel, and navigate with clickable path segments.
- Follow a symbolic link when explicitly opening it and monitor transfers across tabs in a single panel.

## Accessibility and diagnostics

- Windows UI Automation and Linux AT-SPI expose tabs, the command palette, the search field, and the active terminal's visible text, cursor, and selection.
- Open a dedicated recording tab to save a terminal replay fixture from the command palette. Use `aster --replay-vt-fixture FILE` to check the fixture with four VT stream chunking strategies.
