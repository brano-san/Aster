Aster 0.3.0 adds a file panel and port forwarding for SSH, file transfer in any terminal, serial ports, administrator tabs on Windows and a Russian interface.

## New

- File panel for SSH tabs (Ctrl+Shift+O), over the same connection. Browse, upload and download files and whole folders with progress and cancelling, create, rename and delete, change permissions, and drop files onto the panel to upload them. F4 opens a remote file in your editor and uploads every save back to the server.
- Port forwarding from ~/.ssh/config: LocalForward, DynamicForward (SOCKS4, 4a and 5) and RemoteForward start with each connection.
- Tabs to a host that is already open reuse its login. Turn this off with "Share connections".
- SSH passwords and key passphrases can be kept in the system credential store and are used on the next login.
- SSH agent forwarding when the host config or the settings ask for it; IdentityAgent is honoured.
- ZMODEM file transfer in every tab, local, SSH or serial. Incoming files are confirmed first and saved to Downloads; to send, drop files onto the pane or type their paths. Esc or Ctrl+C cancels a running transfer.
- Serial ports. Detected ports appear as profiles; set speed, framing and flow control in a profile of your own, for example COM3:115200,8N1.
- Saved passwords at sudo and other password prompts: Ctrl+Shift+Enter types the saved one, and a password that worked can be saved.
- Profiles on the settings screen: create, copy, edit, delete and choose the default.
- Keyboard shortcuts are edited on the settings screen by pressing the new keys; a shortcut taken from another action is freed there.
- Administrator tabs on Windows: "New administrator tab" in the command palette or "Duplicate as administrator" in the tab menu runs the shell with administrator rights after the system prompt, while the window stays a normal process.
- Russian interface. The new "Language" setting in Appearance follows the system by default and switches at once. The command palette also finds commands by their English names.
- Translucent windows on Linux.

## Fixed

- Translucent windows are no longer darker under the tab bar and the terminal background.
