Aster 0.4.0 adds Telnet and raw TCP connections, and per-profile line handling with login scripts for serial, network and SSH sessions.

## New

- Telnet and raw TCP profiles. Give a profile a "Telnet or TCP address" on the settings screen, such as switch.lan, telnet://10.0.0.1:2323 or tcp://host:7000. Telnet negotiates the terminal type and window size and echoes locally until the server takes over echoing. Raw TCP echoes locally and sends Enter as CR LF.
- Quick connect for network addresses: type telnet://host or tcp://host:port into the profile selector (Ctrl+Shift+E).
- Per-profile line handling in a [profiles.stream] table of the config: local echo, a line editor (also for hex bytes), a hex view of the output, newline conversion in both directions and what Backspace sends.
- Login scripts for any profile: [[profiles.stream.login]] steps wait for text or a regular expression and send a reply, with escapes such as \r, \x1b and ф. For passwords, use the saved-password prompt (Ctrl+Shift+Enter), which now works in Telnet and TCP tabs too.

## Fixed

- The first letter typed after a shortcut that produces no character, such as Ctrl+, opening the settings, is no longer lost.
- ZMODEM transfers are not changed by local echo, newline conversion or the line editor.
