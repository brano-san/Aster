Aster 0.12.1 adds a Windows setup wizard for per-user installation without administrator rights.

- Choose an installation folder and whether to add shortcuts to the Start menu and desktop.
- Follow installation progress and choose whether to launch Aster when setup finishes.
- Setup uses the existing installation folder when updating or reinstalling.
- The uninstall wizard keeps profiles and settings by default. It removes Aster's program files and leaves unrelated files in the installation folder.
- The `--install --silent` and `--uninstall --silent` commands remain available for unattended use.
