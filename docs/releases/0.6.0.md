Aster 0.6.0 works with the rest of the system and gets out of the way: a command line that reaches the running Aster, an Explorer menu entry, a terminal-only mode without the tab bar, a reworked profile selector and a log file.

## New

- The profile selector (Ctrl+Shift+E) is split into sections: recent profiles, your own profiles and groups, built-in shells, hosts from ~/.ssh/config and serial ports. Each row has a badge for its kind, shows the command or address next to the name, and the selected row shows "Enter →". "Manage profiles" at the bottom opens the profiles in the settings. Search also matches commands and addresses, and Backspace on an empty search puts the address of an SSH or Telnet profile up for editing.
- Terminal-only mode for tiling window managers: the "Tab bar" setting hides the tab bar and window buttons always, or only while there is a single tab. Ctrl+Shift+B shows or hides it at any time, and switching tabs without it shows the tab name for a moment.
- Command line. `aster DIR` opens a tab in a folder, `aster run -- CMD ARGS` opens a tab running a command, `aster profile NAME` opens a profile, `aster paste TEXT` pastes into the active tab, and `aster --version` and `aster --help` print information.
- Starting Aster again hands the request to the Aster that is already running instead of starting a second copy: plain `aster` opens a new window there, the commands above open their tab in the last active window.
- A tab started with `run` stays open after the command finishes so its output can be read, and it is not run again when tabs are restored.
- "Open in Aster" in the menu of folders, folder backgrounds and drives in Windows Explorer. Turn it on with "Explorer menu" in the new System section of the settings.
- Aster writes a log file next to its config. "Open the log folder", "Report a problem" (a prefilled issue with the version and system) and "Open the config file in an editor" are in the command palette.
