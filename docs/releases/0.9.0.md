Aster 0.9.0 updates itself, reworks the settings and profiles, and brings a large round of SSH, serial, tab and window features.

## New

- Automatic updates. Aster checks for a new version on start and offers it in a notice with the release notes, a download progress bar and Cancel. Updates are signed and verified before they are installed; the executable is replaced with a rollback if anything fails, a folder that needs administrator rights asks for them once, and Aster restarts with your tabs restored. "Check for updates" on the Application page checks on demand, and the automatic check can be turned off there.
- Profiles page as a tree: your groups nested by parent, ungrouped profiles and the built-in sections, collapsible, with kind badges, marks for the default and hidden profiles and a ▶ button (or F5) that opens a profile in a new tab without leaving the settings.
- Group editor: name, parent group, color and icon, deleting a group moves its profiles to Ungrouped. Groups and each connection type have their own defaults, layered type → group → profile.
- Tabbed profile editor per connection type: General, Command (command line, start folder, run as administrator, environment), SSH options, Serial (port, speed or "ask when connecting", frame, flow control, slow send), Network, Stream and Login script.
- Profiles: what happens when a session ends (keep, reconnect or close), hidden profiles, templates for new profiles, Save as profile from a running tab and saved split layouts.
- New Window settings page; segmented choices; font fields suggest installed font families; several shortcuts per action; a Config file page showing the file, its parse status with line and column, and the defaults; the Application page shows the version and links to the release notes.
- Alt as Meta, a modifier for opening links, pasting line breaks as spaces, taskbar attention on a background bell and a setting to open a terminal on start.
- SSH: per-profile connection options, asking for a missing user, keys found and remembered by fingerprint, colored service messages, algorithm choice and X11 forwarding.
- Serial: ask for the speed when connecting, change speed or send a break on the fly, slow byte-by-byte sending and reconnecting a port that comes back.
- Tabs: pinning, a tab bar on any side with fit or fixed widths, tab numbers, tabs in full screen, switching in recent order and a notification when a command finishes.
- Window: interface density, a switch for animations, a start page when the last tab closes, an optional tray icon on Windows and a portable mode with a data folder next to the executable.
- Rendering: ligatures, a fallback font, a minimum contrast ratio, buffer export and copying as HTML.
- Saved passwords can live in an encrypted vault inside the config, with a Vault settings page and auto-lock; the system credential store remains the fallback.
- Terminal identification and debug commands for the buffer and raw output.

## Changed

- Terminal output is paced so streaming programs no longer starve the window.
- The glyph atlas evicts the least recently used shelves instead of resetting.
- Font, padding and cursor settings moved to the Appearance page; window settings moved to the new Window page.

## Fixed

- SFTP edits of the same size are detected reliably.
